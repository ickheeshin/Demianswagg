# Jarvis Office Colony (Skeleton)

림월드 감성의 "방 안에서 일하는 6명의 에이전트" 시스템을 빠르게 시작할 수 있도록 만든 뼈대 프로젝트입니다.

## 목표
- 에이전트 수: 6명
- 도메인: 투자, 코인, 밈코인
- 핵심 운영 규칙:
  - 에이전트는 업무 중일 때만 책상/의자에 착석
  - 대기 상태에서는 기립/이동 상태 유지
  - 에이전트끼리 대화하며 정보 공유 + 상호 학습
  - 최신 고급 정보를 지속 반영해 지식 점수 개선

## 팀 구조 (요청 반영)
- 팀장: **보운** (`agent_01`)
  - 모든 보고 취합, 필터링, 최종 사용자 보고
- 전문 에이전트: **리모** (`agent_02`)
  - 밈코인/크립토 최신 정보 지속 수집
  - 유의미 정보 팀장(보운)에게 우선 보고
- 보고/승인/중요정보 흐름:
  - `일반 에이전트 -> 팀장(보운) -> 사용자`

## 폴더 구조
- `config/agents.yaml`: 팀 구조/보고체계/에이전트 설정
- `src/office_simulation.py`: 시뮬레이션 코어 로직
- `main.py`: 실행 예시
- `web/index.html`: 림월드 스타일 시각 UI 데모

## 가상환경(venv) 생성
```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
```

## 실행
```bash
python main.py
```

## 현재 구현 포인트
1. 중요 업무/승인 업무는 보고 체인을 강제 (`agent -> 보운 -> 사용자`)
2. 에이전트 간 순환 대화 기반 지식 공유 루프
3. "최고 수준 정보" 업데이트 사이클(지식 점수 증가)
4. 리모 전용 인텔 파이프라인 (`리모 -> 보운 -> 사용자`)

## 웹 UI 실행
```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000/web/index.html
```

UI에서 가능한 것:
- 방 안에서 6명 에이전트가 림월드 스타일 폰(pawn)처럼 자유 이동
- 작업 시작 시 책상/의자 쪽으로 이동해 착석 후 업무 수행
- 브리핑 모드에서 중앙 공간에 모여 협업 느낌 연출 (림월드식 집결)
- 업무 종료 시 다시 자유 이동(기립)
- 성장 사이클 로그 실행
